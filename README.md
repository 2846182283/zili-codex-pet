# 紫璃 · Codex 宠物小尺寸清晰版

白发、紫瞳、淡紫龙翼与卷尾的小龙娘宠物素材。清晰版强化主轮廓和眼睛，简化发束与衣纹，优先照顾小尺寸显示时的辨识度。

![紫璃挥手动画预览](assets/zili-clear-preview.webp)

> 非官方、AI辅助制作的宠物素材。角色参考的原作者、原始链接与许可信息尚待补充，详见 [CREDITS.md](CREDITS.md)。

## 包含什么

- 九组动作：待机眨眼、向右跑、向左跑、挥手、跳跃、失落、等待回应、思考工作、审阅。
- 十六个视线方向，共七十三个动作／视线帧，另含一个中性视线帧。
- Codex v2 宠物图集：1536 × 2288，单元尺寸 192 × 208。
- 保留透明度的无损动画 WebP 预览，以及 96 × 104 小尺寸预览。

## 安装

需要具有自定义宠物功能的 Codex 桌面客户端。界面名称可能随版本变化，请以当前客户端为准。

1. 下载本仓库提供的 [zili-pet-clear.zip](dist/zili-pet-clear.zip?raw=true)，然后解压。
2. 找到包含 `pet.json` 和 `spritesheet.webp` 的 `zili` 文件夹。
3. 将整个 `zili` 文件夹复制到 `pets` 文件夹中；下表是安装完成后的最终位置。已有同名宠物时，先备份旧文件夹再替换。
4. 回到 Codex 的设置 → 宠物页面，刷新资源列表，选择“紫璃”并打开宠物显示。

| 系统 | 默认安装位置 |
| --- | --- |
| Windows | `%USERPROFILE%\.codex\pets\zili` |
| macOS | `~/.codex/pets/zili` |

Windows 可在文件资源管理器地址栏输入 `%USERPROFILE%\.codex\pets`；目录不存在时，先进入 `%USERPROFILE%`，按需新建 `.codex` 和 `pets` 文件夹。macOS 可先在终端运行 `mkdir -p ~/.codex/pets` 创建所需目录，再在访达的“前往文件夹”中输入 `~/.codex/pets`，放入 `zili` 文件夹。自定义过 `CODEX_HOME` 时，应改用该数据目录下的 `pets/zili`。macOS 路径说明未经本次实机验证。

最终文件层级应为：

```text
pets/
└── zili/
    ├── pet.json
    └── spritesheet.webp
```

两份文件必须放在一起，保留原文件名。不要形成 `pets/zili/zili/` 的多层目录。预览图片无需放入宠物目录。

## 常见问题

**宠物列表里没有紫璃。**  
检查文件层级与文件名，再刷新宠物列表。特别注意不要把压缩包本身放入宠物目录，或让解压后的文件多套一层文件夹。

**替换后还是旧外观。**  
先确认替换的是清晰版图集，再刷新宠物列表。可以临时选择另一只宠物后重新选择紫璃，或隐藏后重新显示；仍未更新时再重新打开应用。是否已经加载新版，以实际画面为准。

**相邻视线方向看起来很接近。**  
部分中间角度的区别较细微。十六方向表示离散的视线素材，不保证每一对相邻角度都有同等明显的视觉变化。

**能否把素材用于其他项目或商用？**  
本仓库尚未提供角色参考及图像素材的明确再使用许可，也没有为它们附加 MIT 或 CC0 等许可。请先阅读 [CREDITS.md](CREDITS.md) 中的来源状态。
